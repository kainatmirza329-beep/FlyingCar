# FlyingCar

Volt Sky 3D: a 3D flying car game in one HTML file.

- Open `index.html` in a browser, or host it with GitHub Pages.
- FLY (Space or the FLY button) lifts the car. Let go to fall.
- Land on the green pad in the parking lot and stop inside it to finish the level.
- Controls: arrow keys or WASD to drive, Space to fly, Shift for handbrake, Esc to pause, R to restart.
- Three.js is embedded in the file, so it works offline.
